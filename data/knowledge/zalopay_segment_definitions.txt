ZaloPay Payment Segment Definitions

SEGMENT: domestic_direct
Description: Wallet top-up via domestic card, Vietnam-issued
Key appIDs: 454 (app_1), 4093 (app_2/PSP), 12 (app_3/Telco), 4698 (app_4/Telco), 4699 (app_5/Telco), 15 (app_6/Game)
Merchants: merchant_8 (direct), merchant_7 (PSP), merchant_3 (Telco), merchant_2 (Telco), merchant_1 (Game)
Primary risk: ATO (Account Takeover) via stolen domestic cards, bank_1 cards historically top contributor
Control: limit 20M VND/24h/card (deployed 28-Apr-2026)

SEGMENT: international
Description: International card / gateway transactions
Key appIDs: 149 (app_7/Game), 3762 (app_8/Game), 9999 (app_9/Entertainment), 579 (app_10/Entertainment), 2391 (app_11/Telco), 6699 (app_12/Telco)
Merchants: merchant_1 (149, 3762), merchant_4 (9999), merchant_5 (579), merchant_3 (2391), merchant_6 (6699)
report_cat breakdown: Game (149, 3762), Entertainment (9999, 579), Telco (2391, 6699)
Primary risk: CNP (Card Not Present) via gaming/telco appIDs using international stolen cards
Control: targeted appID rule → BIN-level limit → foreign BIN blocking

SEGMENT: domestic_napas
Description: Domestic NAPAS card transactions routed via BIN-level or SME merchant path
Key signals: BIN concentration, SME merchant self-payment behavior, high ticket size
Primary risk: SME merchant collusion, BIN 970436 historically problematic
Control: block high-risk BIN + deactivate fraud-flagged SME merchants

SEGMENT: wallet
Description: ZaloPay wallet-to-wallet / P2P / IBFT transfers
pmcID: 38 (ZaloPay wallet)
Primary risk: ATO patterns, fund-out after top-up fraud

SEGMENT: others
Description: Remaining appIDs not in above segments. Low contribution typically.

PAYMENT METHOD (pmcID) MAPPING:
pmcID 36: Credit card (international) — primary international fraud vector
pmcID 41: Debit card (international/domestic) — primary international fraud vector
pmcID 38: ZaloPay wallet (IBFT)
pmcID 39: Domestic NAPAS
